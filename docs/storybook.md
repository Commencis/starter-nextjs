# Storybook

Storybook 10 with `@storybook/nextjs-vite`. Run `pnpm storybook`.

- New `ui`, `layout`, and `shared` components get a colocated `X.stories.tsx`.
- Title by layer: `Components/UI/Button`, `Components/Layout/Container`, `Components/Shared/ResponsiveImage`.
- Check the a11y panel (`@storybook/addon-a11y`) before finishing.
- Run `pnpm storybook:build` before finishing.

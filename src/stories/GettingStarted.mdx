# Commencis Starter Storybook - Design System

This is the UI workspace for **Commencis Starter Next.js**: develop and review React components in isolation from the Next.js app, document APIs and variants, and share usage with design and engineering.

## Writing stories

- Place stories beside components using the `*.stories.tsx` naming pattern so behavior stays close to the implementation.
- Use **Docs** for descriptions and controls; use **Accessibility** in the addons panel to catch a11y issues early.

## Tech notes

This instance uses the **Next.js + Vite** Storybook framework (`@storybook/nextjs-vite`), global styles from the app, and the font stack applied via decorators. So stories should feel close to production rendering.
